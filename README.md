# «Алхимик» — квиз для Bothost

Готовое веб-приложение по сценарию станции «Алхимик».

## Что есть

- 3 раунда, 17 вопросов.
- 45 секунд на каждый вопрос (`QUESTION_TIME=45`).
- `/admin` — администратор: старт, раскрытие ответа, следующий вопрос, сброс, таблица команд.
- `/screen` — общий экран для проектора/монитора.
- `/play` — страница игроков; команды подключаются по коду комнаты.
- Результаты хранятся в SQLite в `/app/data`, чтобы не пропадать между перезапусками при постоянном хранилище Bothost.

## Деплой на Bothost

1. Загрузите этот проект в GitHub/GitLab.
2. В Bothost создайте проект/бот и укажите Git URL.
3. Включите домен. Bothost поддерживает веб-приложения и проксирует HTTPS на внутренний порт приложения.
4. Порт: `8000`.
5. Переменные окружения:
   - `PORT=8000`
   - `ADMIN_PASSWORD=...` — придумайте пароль администратора.
   - `QUESTION_TIME=45`
   - `DATA_DIR=/app/data`
6. После деплоя откройте:
   - `https://ВАШ_ДОМЕН/admin`
   - `https://ВАШ_ДОМЕН/screen`
   - `https://ВАШ_ДОМЕН/play`

На стартовом экране админ-панели после нажатия «Старт / новый раунд» появится код комнаты и готовые ссылки для игроков и общего экрана.

## ВК

В текущей версии VK не обязателен: игроки могут заходить по обычной ссылке. При необходимости позже можно добавить VK Mini App или кнопку/бота, который будет открывать `/play`.
