# Алхимик — Bothost v5

Интерактивный квиз для размещения на Bothost.

## Адреса

- `/admin` — панель ведущего
- `/screen` — общий экран
- `/play` — игроки
- `/health` — проверка запуска

## Переменные окружения

```text
ADMIN_PASSWORD=ваш_пароль
QUESTION_TIME=45
DATA_DIR=/app/data
```

## Что реализовано

- 3 раунда, 17 вопросов из сценария «Алхимик»
- 45 секунд на вопрос
- QR-код на общем экране
- код и прямая ссылка на игру
- список подключившихся участников и онлайн-статус
- управление: запустить, показать ответ, следующий вопрос, новый квиз, завершить и показать итоги
- лидерборд в админке, на общем экране и у игроков
- подсветка ответа: правильный зелёным, неверный ответ игрока красным
- реакции 👍 😊 ❤️ 🔥 без ограничения количества нажатий
- анимация реакций на общем экране
- адаптивная мобильная версия
- FastAPI lifespan вместо устаревшего `on_event`
