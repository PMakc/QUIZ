# Алхимик — Bothost v6

Веб-квиз для размещения на Bothost.

## Маршруты
- `/admin` — панель ведущего и конструктор
- `/screen` — общий экран + QR + реакции + финальные итоги
- `/play` — мобильная страница игроков
- `/health` — проверка версии

## Возможности
- до 3+ произвольных раундов;
- любое количество вопросов;
- 45 секунд по умолчанию, можно изменить глобально;
- индивидуальное время на вопрос;
- типы: один вариант, несколько вариантов, верю/не верю, вписать слово;
- фото к вопросу (JPG/PNG/WEBP/GIF);
- правильный ответ зелёный, неправильный ответ игрока красный;
- QR-код на общем экране;
- повторяющиеся реакции 👍 😊 ❤️ 🔥;
- список участников и рейтинг;
- финальный экран итогов;
- SQLite и `/app/data` для постоянных данных.
