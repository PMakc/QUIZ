# Алхимик — Bothost v8

Веб-квиз для Bothost.

## Маршруты
- `/admin` — ведущий + конструктор
- `/screen` — общий экран + QR + реакции + проценты + подсветка правильного ответа
- `/play` — мобильная игра
- `/health` — проверка версии

## Настройка
Переменные:
`ADMIN_PASSWORD=...`
`QUESTION_TIME=45`
`DATA_DIR=/app/data`

Порт: `8000`.

## Важные изменения v8
- правильный ответ выбирается кликом прямо в редакторе;
- для одиночного выбора — radio, для множественного — checkbox;
- старые неправильно сохранённые ответы вида `["\"ПРАВДА\""]` автоматически исправляются при старте;
- после отправки ответов варианты и кнопка блокируются;
- после ответа показывается распределение процентов по вариантам;
- после раскрытия правильный ответ зелёный, ошибочно выбранный — красный;
- на общем экране правильная кнопка становится зелёной;
- реакции считаются без лимита;
- после сброса старый team_code перестаёт работать, телефон возвращается к регистрации.
